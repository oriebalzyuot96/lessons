⁦C++⁩ للمبتدئين

  1. أول برنامج والإخراج std::cout.
  2. المتغيرات والأنواع والإدخال std::cin.
  3. القسمة الصحيحة، وif / else، وحلقة for.
  4. دالة بسيطة (function).

أهلاً! أنا المعلمة Orieb G. سنكتب معاً أول برامجك بلغة ⁦C++⁩ خطوة بخطوة.

أول برنامج (Hello)

hello.cpp
#include <iostream>

int main() {
    std::cout << "Hello, Orieb G!\n";
    return 0;
}
$ ./a.out Hello, Orieb G!

#include : مكتبة الإدخال والإخراج. int main(): نقطة بداية البرنامج. ⁦return 0⁩;: انتهى بنجاح.

كل برنامج يبدأ من الدالة main. نضمّن مكتبة iostream لنطبع باستخدام std::cout، ونعيد صفراً عند النجاح.

المتغيرات والأنواع (variables & types)

vars.cpp
#include <iostream>
#include <string>

int main() {
    int age = 20;
    double gpa = 3.58;
    char grade = 'A';
    bool passed = true;
    std::string name = "Sara";
    std::cout << name << " " << age << " " << gpa
              << " " << grade << " " << passed << "\n";
    return 0;
}
$ ./a.out ⁦Sara 20 3.58 A 1⁩

لكل متغير نوع: int للأعداد الصحيحة، وdouble للكسور، وchar لحرف، وbool لصح أو خطأ، وstring للنصوص. لاحظ أن true تُطبع 1.

الإدخال (input)

input.cpp
#include <iostream>

int main() {
    int age;
    std::cout << "Enter your age: ";
    std::cin >> age;
    std::cout << "Next year you will be " << age + 1 << "\n";
    return 0;
}
$ ./a.out ⁦Enter your age: 19⁩ ⁦Next year you will be 20⁩

المخرجات عند إدخال 19.

نقرأ من لوحة المفاتيح بـ std::cin. إذا أدخل المستخدم 19 يطبع البرنامج 20.

القسمة الصحيحة (integer division)

division.cpp
#include <iostream>

int main() {
    std::cout << 7 / 2 << "\n";    // integer division
    std::cout << 7 / 2.0 << "\n";  // double division
    std::cout << 7 % 2 << "\n";    // remainder
    return 0;
}
$ ./a.out 3 3.5 1

سبعة على اثنين تساوي 3 لا 3.5 لأن العددين صحيحان! إذا كان أحدهما كسرياً نحصل على 3.5، والعملية % تعطي الباقي.

الشرط if / else

grade.cpp
#include <iostream>

int main() {
    int mark = 85;
    if (mark >= 90) {
        std::cout << "A\n";
    } else if (mark >= 80) {
        std::cout << "B\n";
    } else {
        std::cout << "C or below\n";
    }
    return 0;
}
$ ./a.out B

نختبر الشروط بالترتيب: 85 ليست أكبر من أو تساوي 90، لكنها أكبر من أو تساوي 80، فيطبع B.

الحلقة for

squares.cpp
#include <iostream>

int main() {
    for (int i = 1; i <= 5; ⁦i++⁩) {
        std::cout << i * i << " ";
    }
    std::cout << "\n";
    return 0;
}
$ ./a.out ⁦1 4 9 16 25⁩

for (init; condition; update): التهيئة مرة واحدة، ثم الشرط قبل كل دورة، ثم التحديث بعدها.

حلقة for تكرر الأوامر: نبدأ من 1 ونستمر حتى 5، ونطبع مربع كل رقم: 1 و4 و9 و16 و25.

الدوال (functions)

area.cpp
#include <iostream>

double area(double r) {
    return 3.14159 * r * r;
}

int main() {
    std::cout << area(2.0) << "\n";
    return 0;
}
$ ./a.out 12.5664

⁦3.14159 × 2 × 2 = 12.56636⁩، وstd::cout يطبع افتراضياً 6 أرقام معنوية: 12.5664.

الدالة تأخذ مدخلات وتعيد نتيجة. area تحسب مساحة دائرة نصف قطرها 2، وتطبع cout الناتج بست خانات معنوية: 12.5664.

أخطاء شائعة

  • ✗ نسيان الفاصلة المنقوطة ; ✓ كل تعليمة تنتهي بـ ;
  • ✗ ⁦if (x = 5)⁩ ✓ المقارنة بـ ⁦== : if (x == 5)⁩
  • ✗ ⁦7 / 2 = 3.5⁩ ✓ مع ⁦int: 7 / 2 = 3⁩
  • ✗ متغير بلا قيمة ابتدائية. ✓ ابدأ كل متغير بقيمة: ⁦int sum = 0⁩;

أكثر الأخطاء: نسيان الفاصلة المنقوطة، واستخدام = بدل == في المقارنة، والقسمة الصحيحة، ومتغيرات بلا قيمة ابتدائية.

الخلاصة

  • #include وint main() وstd::cout / std::cin.
  • الأنواع: int, double, char, bool, std::string.
  • if / else، وfor، والدوال.
